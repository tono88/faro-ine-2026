# Ejemplos ficticios

Todo lo de esta carpeta es **inventado por el equipo** para demostrar la herramienta. No son datos
del INE ni de ninguna institución y no describen a personas reales.

- `envio_hechos_transito.csv`: envío de ejemplo para la solicitud `hechos-transito-v1`.
- `edificaciones_ficticias.csv`: serie anual de edificaciones para tres municipios.
- `operadores_ficticios.csv`: 19 operadores sin nombre (`OP-01`...) con el lugar poblado donde
  "viven". Los códigos de lugar son reales (catálogo del Censo 2018, Sololá); quién vive dónde es
  inventado.
- `cotizaciones_ficticias.csv`: cotizaciones inventadas de cuatro productos para probar el
  cálculo del precio de referencia.
- `puestos_ficticios.csv`: 7 puestos de trabajo en lugares poblados reales de Sololá y cuántos
  operadores necesita cada uno (inventado).
- `tabla_codigos_ficticia.csv`: ejemplo de tabla de códigos de una institución para cargar en
  "Equivalencias".
- `solicitud_hechos_transito.toml`: solicitud de ejemplo para probar `faro recibir` con
  `envio_hechos_transito.csv`. No aparece en la pantalla.

- `tasas_extraccion_ficticias.csv`: tabla **ficticia** de utilización y tasas de extracción para probar
  la calculadora de derivados de la Hoja de Balance de Alimentos. Los productos y los porcentajes son
  inventados para mostrar el formato; las tasas reales las define el INE.
